Device42, a Freshworks company, provides a comprehensive, agentless discovery and dependency mapping solution that spans legacy mainframes to cloud containers. It helps IT teams automatically discover, map, and manage their infrastructure, applications, and services, delivering real-time visibility and insights for better operations and planning.

**Areas:** IT Asset Management · IT Discovery · CMDB · Data Center Infrastructure Management · IT Operations · Compliance · Cloud Migration · Sustainability

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Device42: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
